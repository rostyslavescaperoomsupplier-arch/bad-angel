# Bad Angel — векторный логотип и эмблема

Векторизация растровых исходников `logo.PNG` (текстовый логотип) и `IMG_3468.PNG`
(круглая эмблема: монограмма BA с рожками, нимбом, крылом и хвостом).

## Текстовый логотип (BAD ANGEL / BEAUTY SALON)
- `bad-angel-logo-black.svg / .eps / .pdf` — сплошные чёрные буквы, прозрачный фон
- `bad-angel-logo-white.svg` — белая версия для тёмных поверхностей
- `bad-angel-logo-gold-dark.svg` — золотой градиент на тёмном фоне
- `bad-angel-logo-engraved-black.svg / .eps / .pdf` — «гравировка» (линии хром-эффекта)

## Эмблема (монограмма BA с ангелом/демоном)
- `bad-angel-emblem-line-black.svg / .eps / .pdf` — линейная графика, прозрачный фон
- `bad-angel-emblem-line-white.svg` — белая линейная
- `bad-angel-emblem-solid-black.svg / .eps / .pdf` — жирная сплошная монограмма + линейный текст
- `bad-angel-emblem-solid-white.svg` — то же белым
- `bad-angel-emblem-gold-dark.svg` — золото на тёмном круге (как оригинал аватарки)

## Для CorelDRAW
Формат `.cdr` закрытый — напрямую его не создать, но Corel без потерь импортирует
всё, что здесь лежит: **File → Import (Ctrl+I)** → выбрать `.eps` (классика для
типографий), `.svg` или `.pdf`. Всё в кривых, шрифты не нужны, масштаб любой.
После импорта можно сделать **Save As → .cdr**.

EPS/PDF — плоский чёрный (типографии сами красят в Pantone/CMYK);
градиентные и белые версии — в SVG.
